# no1coder/homebrew-tap

Homebrew casks for apps by [@no1coder](https://github.com/no1coder).

## Cubby

[Cubby](https://github.com/no1coder/cubby) is a native macOS clipboard manager with screenshots, annotation and in-place translation.

```sh
brew install --cask no1coder/tap/cubby
```

Upgrade with `brew upgrade --cask cubby`. The cask is updated automatically when a new Cubby release is published.

小格子（Cubby）：原生 macOS 剪贴板工具。安装：`brew install --cask no1coder/tap/cubby`，升级：`brew upgrade --cask cubby`。
